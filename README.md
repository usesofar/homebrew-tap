# usesofar/homebrew-tap

```
brew install usesofar/tap/sofar
```

`Formula/sofar.rb` is generated by
[`packaging/homebrew/formula.mjs`](https://github.com/usesofar/sofar/blob/main/packaging/homebrew/formula.mjs)
in usesofar/sofar. Don't edit it by hand. `.github/workflows/bump.yml` checks npm's
`latest` every six hours, proves the new formula (install, `brew test`,
`brew audit --strict`) and commits it.
